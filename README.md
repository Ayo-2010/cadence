# Cadence

A warm, local-first habit tracker with a twelve-week heatmap, streak analytics and weekday insights. Built with plain HTML, CSS and JavaScript.

**Live demo:** https://ayo-2010.github.io/cadence/

## Features

- Add and remove habits with a name, icon and colour
- Twelve-week heatmap for every habit, with future days locked
- One-tap check-in for today and clickable past days
- Current streak, best streak, completion rate and thirty-day summary
- Fourteen-day activity chart and weekday strength breakdown
- Automatic pattern note that names the steadiest habit and strongest weekday
- Switch between eight, twelve and sixteen week views
- Everything saved in localStorage
- Responsive layout down to 390px, reduced motion support and a global `[hidden]` rule

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
